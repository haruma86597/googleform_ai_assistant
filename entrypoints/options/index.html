GoogleForm AI Assistant

設定

Gemini API設定

Google Gemini のAIモデルを使用して回答を生成します。 キーはブラウザのローカルストレージへ安全に保存されます。

APIキーの取得方法

Gemini APIを利用するには無料のAPIキーが必要です。以下の手順に沿って取得してください。

1

Google AI Studio にアクセス

下記のボタンからGoogle AI StudioのAPIキー管理画面を開きます。

Google AI Studio を開く
2

「Create API key」をクリック

画面上部または左側にある青色の「Create API key」ボタンをクリックします。

3

新しいプロジェクトで作成

ポップアップ画面が開いたら、「Create API key in new project」を選択してキーを作成します。

4

キーをコピーして保存

生成されたキーをコピーし、左側の「Gemini APIキー」欄に貼り付け、「保存」を押します。

拡張機能の使い方

  1. 1 APIキーを保存した状態にする
  2. 2 Googleフォームの回答・問題画面を開く
  3. 3 拡張機能アイコンをクリックし、「解答をハイライト」ボタンを押す
  4. 4 AIが導き出した正解の選択肢が、自動で選択されます

安全性と料金について

完全に無料で利用できます。
Google AI Studioの無料枠（Free tier）を使用するため、クレジットカードの登録すら必要ありません。無料枠ではリクエスト制限（Gemini 3.5 Flash-liteの場合、1分間に15リクエストまで等）がありますが、通常の個人利用の範囲であれば十分な上限です。有料プランへアップグレードしない限り、自動で請求が発生することはありません。

入力されたキーは、利用者のブラウザ（拡張機能専用のローカルストレージ）にのみ保存されます。
拡張機能の開発者を含め、外部の第三者サーバー等へキーが送信されることは絶対にありません。APIキーはGoogleフォームの問題を解析する目的で、GoogleのGemini APIエンドポイントと直接通信するためだけに利用されます。

貼り付けたキーの前後に余分なスペース（空白文字）や改行が入っていないか再度確認してください。キーは通常、AIzaSy から始まる39文字前後の英数字・記号で構成されています。また、新規作成したばかりのAPIキーは、世界中に反映され有効化されるまでに数分かかる場合があります。
